# DevouringBeast - 当前游戏设计

## 1. 定位

- 类型：2D 俯视角 Roguelike 动作游戏。
- 平台：Android 横屏。
- 核心差异：吸力伤害、吸入尸体/物品、吐出攻击和吞噬升级结合的房间清理玩法。
- 地图节奏参考《以撒的结合》的相邻房间结构，但没有隐藏房间与隐藏门。

## 2. 核心流程

```text
进入房间
  -> 门关闭并生成敌人
  -> 移动、吸力伤害、吐出攻击
  -> 消灭全部敌人
  -> 门开启、拾取补给、选择下一个相邻房间
  -> 击败 Boss 后选择继续探索或进入下一层
```

## 3. 楼层规则

- 每层固定 10 个相同大小的连通房间。
- 1 个初始普通房、1 个精英房、1 个 Boss 房、7 个普通房。
- 初始房绝不为精英或 Boss。
- 房间类型在楼层生成时确定，本层内不会改变。
- 玩家可按任意顺序探索可达房间。
- Boss 清理后出现下一层入口，但不会强制结束当前层。

## 4. 房间规则

- 相机固定在当前房间中心，房间完整覆盖游戏视口。
- 未清理房间进门后封锁所有出口。
- 普通/精英房计时 60 秒，Boss 房计时 120 秒。
- 倒计时最后 3 秒转为红色；Boss 房在倒计时条下方显示固定的红色 Boss 总血条，其他房间不显示。
- 倒计时不是通关条件，也不会触发下一波。
- 超时后以低谷接近熄灭、峰值短促的警告红光提示危急状态；红光峰值随连续增长的全局倍速明显加重并封顶，到达上限后仍持续闪烁，HUD 保持清晰。
- 只有全部击杀后才开门。
- 清房后停止生成新的可吸入环境物品，已生成物品继续保留。
- 已清理房间保持开放且不会再次刷怪。

## 5. 玩家操作

| 操作 | 行为 |
| --- | --- |
| 移动 | 虚拟摇杆或键盘移动，受当前房间边界限制 |
| 吸入/吐出 | 口中为空时施加吸力，有内容时吐出能量球 |
| 吞噬 | 消耗口中内容并累计升级质量 |

吸入期间主按钮图标不因物品入口而即时切换，吸入结束后才提交口中状态。长按吸入或蓄力时按钮红色闪烁，达到上限后保持红色，结束操作后复原；蓄力音效不循环。

教皇的教化按钮在拥有蓄力技能时也可长按蓄力，教化能量球继承蓄力伤害。吞噬/教化导致升级时，动作音效和升级音效完整播放；技能卡选择固定播放 `rogue_select`。

存活敌人不能直接入口；吸力先造成持续伤害。尸体与普通环境物品满足质量/吸力规则后可以进入口中。

## 6. 升级

- 吞噬只累计质量，不区分物种或标签。
- 玩家外观不随吞噬内容变色。
- 达到质量需求后展示最多 3 个合法技能。
- 所有合法技能等权随机，不根据吞噬进度偏向学派。
- 前置技能、最大等级、Faith 互斥和当前形态收益仍会过滤候选。
- 天使的无消耗能量球继承玩家当前全部可用的吐出、分裂、穿透和状态技能；取得天使不会清空既有技能。
- 天使、恶魔的击杀质量收益为敌人质量的 2 倍。
- 超出本级需求的质量保留到下一级。

## 7. 掉落与生命

- 半心恢复 1 点，整心恢复 2 点。
- 心形掉落只能通过玩家接触拾取，不受吸力影响。
- 治疗不会超过当前生命上限。
- 玩家只缺半心而触碰整心：恢复半心，原整心变为半心留在原地。
- 掉落物整层持久化，离开房间不会消失，进入下一层才清理。

## 8. 视觉

- `new_map.png` 使用手工切分的墙角、开启门、墙和地板 Tile；每个房间由 16 x 9 Tilemap 按结构绘制，不直接使用整张图片。地板由原图中的 5 个连续切片组成，通过水平往返镜像和逐行垂直镜像延展，邻接边缘保持同源像素连续，不再显露逐格硬接缝。
- 关闭状态下门位使用墙 Tile；房间清理后，相邻方向中心的墙替换为按方向旋转的开启门 Tile。
- 可移动和环境生成范围向墙内侧收缩，角色与怪物不能进入墙体可见厚度范围。
- 玩家、敌人、落地物品、掉落物和楼层入口拥有简易椭圆黑影。
- 有落地过程的对象在开始下降时先在地面出现小影子，落地期间影子逐渐扩大。
- 小撒旦、撒旦、肉山和蜘蛛的精灵离地与物理根节点分离；肉山压扁攻击会完整飞出视口再落向目标。
- 撒旦系火球有螺旋下降火焰拖尾和落点影子，落地后火球消失并留下 2 秒灼烧区；撒旦火球额外从落点发射四颗子弹。
- 危急状态以全屏半透明红色覆盖表现，不遮挡输入。

## 9. 音频

- 普通/精英房使用战斗音乐。
- Boss 房切换 Boss 战斗语义。
- 选技能或 Game Over 时普通 SFX 可暂停，BGM 保持播放。

## 10. 后续验收重点

- 房间布局可读性与门方向辨识。
- 危急状态强化速度与红屏强度。
- 普通、精英、Boss 房敌人数量与首层难度。
- 血量掉落概率和整心/半心比例。
- Android 横屏不同分辨率的固定视口与 UI 遮挡。
- 长局对象池、状态订阅、协程与 GC 稳定性。
